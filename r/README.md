# R Utilities

Reusable R functions and utilities for clinical programming and CDISC workflows.

## Available Utilities

R utilities are currently under development and will be added to this directory
as they are finalized.

Future utilities will be documented here with their:

- Purpose and functionality
- Function parameters
- Dependencies
- Usage examples
- Input and output requirements

## Structure

Each reusable R utility will be maintained in this directory and documented in
this README as it is added to the repository.

## Usage

Study-specific R programs, data, specifications, outputs, and configuration
should be maintained in the respective study repository rather than in this
global utilities repository.
